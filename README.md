# AgentLens — project site

Static source for https://anonymousz77.github.io/AgentLens/, served from the `gh-pages` branch.

Plain HTML, CSS and JavaScript with no build step and no third-party requests (fonts are self-hosted).
The score calculator in `assets/site.js` mirrors `src/scoring/score.ts` with the default weights.
Terminal output on the page was captured from real AgentLens runs.

Edit `index.html` / `assets/*`, commit, and push to `gh-pages` to update the live site.
